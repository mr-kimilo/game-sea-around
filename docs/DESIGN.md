# 设计与玩法细节（Design Notes）

本文件记录游戏的玩法规则、关卡数据、美术与音效实现细节。上手运行请看 [README](../README.md)。

## 背景
制作一款适合6岁左右儿童喜欢的游戏，适当的操作感觉，简单的按键要求，上下左右和2个功能键。
以贪吃蛇为原型，背景在海底，海底有水泡，有鱼游来游去，先生成一个可以控制的圆点，上面有可爱的表情，在张嘴，它吃水里的小鱼，但是也要躲避其他大鱼。
操控
上下左右去吃小鱼，有个加速键，可以加速游走，但是加速有cd，需要等几秒回复才能再次加速，还有一个隐身键，同样有cd，需要回复。两个按键按了之后就有效果，并且有个地方展示这个cd。
技能图标用两种颜色区分状态：冷却中 = 暗灰蓝 + 倒计时；就绪 = 技能本色 + 呼吸光晕；刚转好的瞬间还会闪一圈亮光。
当你被大鱼吃掉，就算输了。
怎么算可以被吃，你开始的重量是5，只能吃重量小于5的鱼，要躲避鱼身上数字大于你的，大鱼你身上数字的鱼可以吃了你，你被吃掉就算输。
数字颜色实时反馈：比玩家轻的鱼显示**绿色加大加粗 + 绿色光晕**，大于等于玩家的鱼显示**红色加大加粗 + 红色光晕**，数字一亮一亮地呼吸闪烁；颜色跟着玩家体重实时变化（玩家从 5 吃到 6，6 以下的鱼立刻变绿），双人模式按离鱼最近的玩家判断。
被吃了可以再来一局（并且可以重新选择难度），没有被吃就可以吃下去，吃到一定数量就过关，下一关，每一关可以设置不同的难度。

关卡设计（共 20 关，难度平滑递增）
参数在 `levels.json`，每关只比上一关提升一点点：

| 参数 | 第1关 | 第20关 | 说明 |
| --- | --- | --- | --- |
| fishCount | 12 | 37 | 鱼的数量，每关 +1~2 |
| fishSpeed | 30~80 | 70~140 | 鱼的游速，逐步变快 |
| fishWeightRange | 1~8 | 1~36 | 鱼的重量上限逐步提高 |
| maxBigFishRatio | 0.15 | 0.42 | 大鱼（重量 ≥ 玩家初始重量5）占场上鱼数的比例上限 |
| bigFishInterval | 5s | 1.8s | 每隔多久才额外放出下一条大鱼 |
| targetWeight | 15 | 38 | 过关需要的重量 |

难度控制要点：
1. 开局场上全是小鱼（重量 < 5），一条都吃不了你；
2. 大鱼按 bigFishInterval 一条一条慢慢出现，且总数不超过 fishCount × maxBigFishRatio，所以“大于初始值的鱼”永远不会超过设定比例；
3. 玩家吃掉鱼后补充的新鱼同样遵守数量与时间限制，并且偏向小鱼，避免难度突变。

鱼种解锁（每关新增一种，颜色与形状都不同）
第 N 关解锁 N 种鱼，第 20 关 20 种全部登场，除第 1 关外每关开场会弹出「新鱼登场：xxx」提示。
图鉴定义在 `js/textures.js` 的 `FISH_SPECIES` 与 `SHAPES`：

1. 条纹小鱼、2. 圆河豚、3. 小水母、4. 旗鱼、5. 小章鱼、6. 比目鱼、7. 银带鱼、8. 小海龟、9. 鲨鱼、10. 灯笼鱼、
11. 鲸鱼宝宝、12. 海星、13. 电鳗、14. 独角鲸、15. 食人鱼、16. 小螃蟹、17. 龙鱼、18. 铁甲鱼、19. 深海巨口鱼、20. 黄金鱼王

地图（菜单里 ← → 或手柄十字键切换，实时预览）
游戏开始前可以在 3 张海底地图之间切换，三者海底世界各不相同，选好后整局游戏（含过关/失败/通关庆祝界面）都使用这张地图，选择会被记住：

| 地图 | 海底世界 |
| --- | --- |
| 热带 | 青绿色暖水 + 金色沙滩，长满左右摇摆的海草，还有分支珊瑚、脑珊瑚 |
| 亚热带 | 蓝色浅海，厚厚的细沙上散布着大礁石和鹅卵石 |
| 北极 | 安静的冰海，雪白沙床上有碎冰，阳光从上方照下几道呼吸的光束，水里一闪一闪波光粼粼 |

实现：`js/textures.js` 里的 `MAPS` 定义地图，`drawSeaBackground(scene, mapKey)` 画静态部分，`createMapFX(scene, mapKey)` 生成动态装饰（摇摆海草 / 呼吸光束与波光）；地图 key 经场景数据在 Menu → Game → End/Victory 之间传递，并存入 `registry` 记住上次选择。

语言（中英文，界面与语音一起换）
菜单里有「语言 Language」一行，三种切法任选：

1. **键盘 L 键**（字母 L，在键盘右侧、K 的右边）；
2. **手柄 L1 / R1**（L2 / R2 也行）；
3. **鼠标 / 手指直接点屏幕上的「中文」或「English」**。

当前语言用【】高亮，选择记在 `localStorage`（`sea_around_lang`），下次打开还是它。切完界面文案与语音播报全部跟着换：菜单、HUD、新鱼登场、过关/失败/通关界面、地图名与描述、20 种鱼名、难度名与评语。

| 语言 | 语音合成语言 | 举例 |
| --- | --- | --- |
| 中文 | `zh-CN` | 「欢迎来到海底吃吃乐，要一个人玩，还是两个人玩？」「一条鱼」「亚热带」 |
| English | `en-US` | “Welcome to Undersea Yum Yum! How many players? One or two?” “one fish” “Subtropical” |

实现：`js/i18n.js`（`LANGS` / `LANG` / `T(key, vars)` 界面句子 / `tx({zh,en})` 取数据名 / `numberWord()`），数据里的名字统一写成 `{ zh, en }`，场景文案一律 `T('key')`。

通关庆祝与评分（VictoryScene）
打赢第 20 关后进入庆祝场景，按时间顺序播放：

1. **所有鱼游来游去**：20 种鱼（外加几条凑热闹）在屏幕里穿梭、摆尾、翻转；
2. **海底火山爆发**：火山从海底升起，熔岩火球抛射 + 火山灰 + 震动闪光，鱼群惊慌上游；
3. **笑脸与评分**：弹出大大笑脸 + 「全部通关！你真厉害！」，然后显示得分与 10 颗黄色五角星。

| 项目 | 规则 |
| --- | --- |
| 计分 | 通关总用时 ≤ 12 分钟 = 100 分；≥ 40 分钟 = 0 分；中间线性换算 |
| 得星 | 10 颗五角星，每 10 分点亮 1 颗（满分 100 = 10 颗全亮） |
| 用时 | 各关耗时累加（失败重打的时间也算），过关界面会显示「累计用时」 |
| 操作 | 空格/Enter 跳过动画；动画结束或跳过后：1 = 再玩一次，2 = 返回菜单（手柄 A/B） |

场景文件：`js/scenes/VictoryScene.js`（庆祝动画 + 评分），由 `GameScene.finish()` 在最后一关通关时启动。

声音（水泡 / 吃到鱼语音表扬 / 大鱼登场提示 / 星星 bing）
全部由 `js/audio.js` 用 Web Audio **实时合成**，语音表扬用浏览器自带的语音合成，**没有任何音频文件**，`file://` 直接打开也有声音。

| 声音 | 做法 | 什么时候响 |
| --- | --- | --- |
| 水泡 | 正弦波快速上滑 + 极短包络（“咕噜”一声），随机间隔连响 1~3 下 | 全程随机出现（海底环境音） |
| 海浪 | 粉红噪声 → 高通+低通，再用 0.07Hz 慢速 LFO 调制音量与亮度 | **已按要求关闭**，代码保留，把 `audio.js` 里的 `WAVES_ENABLED` 改回 `true` 即可恢复 |
| 吃到鱼 | 按当前语言报数：中文「一条鱼 / 二条鱼 / 三条鱼…」、英文「one fish / two fish / three fish…」，每满 3 条再加一句夸奖（真棒！/太棒了！/好厉害！ ↔ Yes!/Very good!/Unbelievable!）；系统没有语音时自动退回一段上扬的 3 音小音效 | 每吃掉一条鱼 |
| 菜单语音 | 欢迎语、按 1/2 播「一个玩家 / 两个玩家」、← → 换地图播地图名、按 L 切语言念一遍语言名（全部跟当前语言） | 菜单里相应操作时 |
| 大鱼登场 | 三声上行铃音（A5 → C#6 → E6），基频 + 泛音 + 点击噪声 | 场上有新的“大鱼”出现时 |
| 星星 bing | 单声铃音，音调一颗比一颗高（C6 开始的大调音阶） | 过关/通关界面上每颗五角星蹦出来时 |

细节：
0. **高清渲染**：画布缓冲按 1920x1080 渲染（逻辑坐标仍是 960x540，各场景相机 `setZoom(2)` 并居中），鱼纹理 3 倍、玩家/火山/水泡纹理 2 倍超采样生成（`textures.js` 里的 `FISH_TEX_SS` / `PLAYER_TEX_SS` / `TEX_SS`），文字统一按 2 倍生成字形（`main.js` 里给 `add.text` 打了全局补丁），在大屏幕上不再发虚；开始界面的文字按统一纵向节奏整齐排列；
1. 浏览器要求先有用户操作才能出声，所以**在菜单里按 1 / 2 开始游戏时声音自动响起**（切场景不会中断，也不会重复叠加）；
2. 语音表扬最快 0.7 秒一句，上一句还在说就跳过这次；如果语音卡住（例如没插音箱）超过 2.5 秒会自动清掉，不会把后面的表扬全堵死；
3. 大鱼提示音 0.5 秒内不重复，避免几条大鱼同时出现时叮叮叮叠成一团；
4. **M 键** 随时静音 / 恢复（状态存在 localStorage，下次打开还记得），各场景右下角显示「声音：开 / 关（M 键切换）」；
5. 接入点：各场景 `create()` 里 `SeaAudio.init(this)` + `SeaAudio.addHint(this)`；吃到鱼在 `GameScene.checkCollisions()` 里调 `SeaAudio.praise()`，大鱼出现（`setFishWeight` 转成大鱼）时调 `SeaAudio.ding()`，星星在 `EndScene.revealStar()` / `VictoryScene` 里调 `SeaAudio.starBing(i)`；自检可用 `SeaAudio.state()`。

每一关的评分（满分 100 = 10 颗黄星）
过关界面（`EndScene`）会给出本关得分，10 颗五角星**从第 1 颗开始一颗一颗蹦出来**，每蹦一颗“bing”一声（音调逐颗升高）：

| 项目 | 规则 |
| --- | --- |
| 计分 | 看本关用时。标准用时 = (目标重量 - 5) × 2.2s + 场上鱼数 × 0.8s，再乘以难度系数（简单 0.9 / 普通 1 / 困难 1.25） |
| 满分线 | 本关用时 ≤ 标准用时 → 100 分 |
| 零分线 | 本关用时 ≥ 标准用时的 2.5 倍 → 0 分，中间线性换算 |
| 得星 | 10 颗黄星，每 10 分点亮 1 颗；没挣到的显示成空星（灰蓝色） |
| 评语 | 按分数给出（完美！/ 非常棒！/ 很棒哦！/ 不错！/ 慢慢来） |

参考值：第 1 关标准用时约 32 秒、第 20 关约 102 秒（普通难度）。函数在 `js/textures.js`：`levelParTime()` / `calcLevelScore()`。
